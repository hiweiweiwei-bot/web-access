# 语文·错题复盘手册（七年级）

> 依据：义务教育语文课程标准（2022）+ 统编版教材
> 现阶段主攻：**默写 + 字词 + 名著**（确定性送分块，C→B 最快的路）

---

## 第一部分：先把知识捡回来（给辅导者的 refresher）

### 中考语文考什么（四大板块 + 大致占比）
| 板块 | 考什么 | 提分难度 | 现阶段优先级 |
|---|---|---|---|
| **积累与运用** | 字音、字形、成语、病句、古诗文默写、名著 | ⭐ 最易（靠背） | 🔴 现在主攻 |
| **古诗文阅读** | 课内文言文、古诗词理解 | ⭐⭐ 中（套路化） | 🟠 跟上 |
| **现代文阅读** | 记叙文、说明文、议论文 | ⭐⭐⭐ 较难（靠方法） | 🟡 教术语 |
| **写作** | 命题/材料作文 | ⭐⭐⭐ 慢（靠积累） | 🟢 每月一篇 |

> **核心判断**：积累与运用是"背了就给分"的硬通货，出卷人没法不给。品言是 C 档，**先把这块的分全拿到，等级立刻能动**。

---

## 第二部分：错因分类表（拿到错题，对照贴标签）

| 错因标签 | 典型表现 | 归类 |
|---|---|---|
| **A. 默写写错字** | 句子记得，字写错（如"final"写成别字） | 会了没拿到 |
| **B. 默写上下句不接** | 给上句接不出下句 | 知识缺口 |
| **C. 字音字形** | 多音字、形近字、易错字读写错 | 知识缺口 |
| **D. 成语误用** | 望文生义、用错对象 | 知识缺口 |
| **E. 阅读脱离文本** | 凭感觉答，不回原文找 | 方法缺口 |
| **F. 阅读术语不会用** | 知道意思，写不出采分点话术 | 方法缺口 |
| **G. 名著记不清** | 人物、情节张冠李戴 | 知识缺口 |
| **H. 作文跑偏/结构乱** | 审题偏、没有结构 | 方法缺口 |

> **复盘做法**：把品言语文错题逐条贴上 A–H，**数哪类最多**。七年级最常见是 A/C/F——这三类都能套路化解决。

## 第三部分：高频易错点 + 正确方法

### 🔴 默写（最该先满分的送分块）
- **易错字策略**：默写本上把**写错过的字单独红笔圈出**，每天专攻这些字，而不是重默整首诗。
- **七上重点必背**（以教材目录为准）：
  - 古诗：《观沧海》《闻王昌龄左迁龙标遥有此寄》《次北固山下》《天净沙·秋思》《峨眉山月歌》《夜雨寄北》《十一月四日风雨大作》《潍县署中画竹》等
  - 文言：《〈论语〉十二章》《诫子书》《狼》《穿井得一人》《杞人忧天》
- **复盘抽查法**：你说上句，她写下句；写错的字当场罚抄 3 遍并圈进易错本。

### 🔴 字音字形
- 重点抓**形近字**（己/已/巳、戎/戍/戊）和**多音字**（朝、行、降、还）。
- 方法：错一个，记一个，**只记错过的**，不撒网背。

### 🟠 现代文阅读（教"采分点话术"——这就是出卷人思维）
阅读题有固定给分模板，背会话术就能拿分：

| 题型 | 万能答题框架 |
|---|---|
| **词语赏析** | "××"一词，（手法/词性），生动写出了……，表达了……（情感） |
| **句子赏析** | 运用（修辞/描写），生动形象地写出了……，表现了……（情感/性格） |
| **修辞作用** | 比喻/拟人→生动形象；排比→增强气势；反问→加强语气 |
| **标题作用** | 概括内容 / 线索 / 双关 / 设置悬念引兴趣 / 点明主旨 |
| **人物形象** | 从（事件/描写）可以看出，他是一个……的人 |

> 复盘时：拿她的阅读错题，**对照看她是不是漏了框架里的某一步**（通常漏"表达了什么情感"）。

### 🟢 名著（七上：《朝花夕拾》《西游记》）
- **《朝花夕拾》**：鲁迅回忆性散文集。重点篇目：《从百草园到三味书屋》《阿长与〈山海经〉》《藤野先生》《父亲的病》《五猖会》。考点：作者情感、人物（长妈妈、藤野先生、范爱农）。
- **《西游记》**：重点情节（大闹天宫、三打白骨精、真假美猴王、三借芭蕉扇）、人物性格（孙悟空、猪八戒、唐僧）。
- 方法：做**人物卡片 + 情节卡片**，每天读 15 分钟随手记。

### 🟢 作文
- 你只批三样：**审题对不对、结构清不清、开头结尾有没有亮点**。
- 帮她攒 **3–5 个万能素材**（一个亲情、一个成长、一个坚持类），反复用熟。

## 第四部分：复盘提问清单（带着她找规律）

拿出语文错题，依次问：
1. "这道默写是字写错，还是根本没背下来？"（分 A / B）
2. "你写错的字，本子上记过吗？"（建易错字本的钩子）
3. "这道阅读，你回原文找答案了吗？还是凭印象写的？"（揪 E）
4. "你答案里有没有写'表达了什么情感'？"（揪 F，最常漏）
5. "这本名著，主角是谁、做了什么、什么性格，你能一句话说清吗？"（查 G）

> 数完标签，**只讲最多的那一类**，其余记进错题本下月再看。
