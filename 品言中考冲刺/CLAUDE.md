## 二、错题"讲透"标准（每道错题必须五段式，按顺序）
1. **回归考纲知识点**：列出这题用到的定理/性质 + 加一句"□ 能否背出"自查。**根因几乎都是知识点不牢，先补根，再讲题。**
2. **诊断**：这题考什么 + 她最可能卡在哪。
3. **触发信号**：为什么会想到这个方法。辅助线 / 设元 / 分类讨论都是**"方法"（不是考纲知识点）**，但都由知识点推出——必须讲清"**看到什么特征 → 该想到什么**"。
4. **规范解答**：∵∴ 格式，每一步标注用了哪条知识点（练书写采分）。
5. **另解对比（若有）**：说明哪个是通法、为什么另一个更繁/更易错。

## 三、交终稿前的自查纠错流程（我自己跑完，别让用户纠）
涉及数学/几何，**交付前逐条过一遍**：

- **A 答案独立验证**：用坐标或具体数值**再算一遍**最终答案，确认无误。
- **B 几何证明逐步验算**：每个"角的加减、边的等量、两侧/同侧关系"都用坐标或具体角度核对——**尤其"是加还是减"**。（教训：题4 误用 ∠ABF=∠ABC−∠CBF，实际是 **＋**，导致整条证明错。）
- **C 图必须验证**：坐标构造 → 渲染 → **截图 Read 自看** → 确认：
  - 几何关系对（垂直/平行/等长/比例）；
  - **证明需要的每一个条件都标在图上**（等长刻度、等角弧、直角符号、平行号）。（教训：手拉手图漏标 ∠AOB=∠COD，就"证不出"。）
  - 图与题文、答案一致（如折叠 B′ 的位置、D 在哪一侧）。
- **D 分类讨论**：遇**动点 / 折叠 / 垂直 / 会出现两解**的情形 → **分情况，每种各画一张图，各列一个一元一次方程**。**禁止用绝对值**把两种情况压成一个式子——初中生看不懂。（教训：题2 用 |2x−140|=90 太抽象，应分两图看"角怎么拼"。）
- **E 方法 vs 知识点**：辅助线/设元先回归它依赖的考纲知识点 + 讲触发信号；若存在"不作辅助线"的另解，简述并对比繁简。（教训：用户质疑"辅助线不在教纲"——要讲清它是由平行线性质推出的通法。）
- **F 认知负荷**：一道题涉及多个模型/方法 → 给优先级（🔴🟡⚪）、提示"一次只学一个"，不要一次堆完。

> 一句话：**先验算、再画图自检、分类各画图、把每个条件标到图上**。做完这些再交，就是"讲透终稿"。

- **G 费曼输出环节**：复盘流程第 7 步——每月复盘日最后 15 分钟，让品言把上月补的"洞"**讲回来**（知识点+例题）。讲不清=没真懂。出材料时可顺带给"她要讲什么"的提纲。

## 四、渲染中文 PDF 的方法（环境已具备）
- 工具：Playwright Chromium 在 `/opt/pw-browsers`（`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`）；中文字体 **WenQuanYi Zen Hei**（HTML 正文与 `<svg> text` 的 font-family 都用它）。
- 流程：写 HTML（含内联 SVG 图）→ 用 Node(CommonJS) `require` playwright，`page.pdf({format:'A4',printBackground:true})` → 用 python 校验页数且 `b'WenQuanYiZenHei' in pdf`（确认字体嵌入）→ **几何图必须再截 PNG 用 Read 自检**。
- LibreOffice 在本环境转换会失败，**用 Playwright**。
