数学 · 七年级考点全解

用法：① 你自己先读一遍把知识捡回来；② 复盘时拿品言的错题，对照各节的「易错警示」找规律；③ 例题可直接当讲解模板。

第一章　有理数

1.1 基本概念

概念含义关键
正数 / 负数大于 0 为正，小于 0 为负0 既不是正数也不是负数
有理数整数 + 分数（可写成分数的数）整数含正整数、0、负整数
数轴规定原点、正方向、单位长度的直线右边的数总比左边的大
相反数只有符号不同的两个数a 的相反数是 −a；0 的相反数是 0
绝对值数轴上点到原点的距离恒 ≥ 0
绝对值法则（必背）：｜a｜ = a（当 a≥0）；｜a｜ = −a（当 a<0）。
即：正数和 0 的绝对值是它本身，负数的绝对值是它的相反数（结果为正）。
例 1　已知 ｜x｜ = 5，求 x。
解：到原点距离为 5 的数有两个 → x = 5 或 x = −5。
(易漏负的那个，绝对值方程常有两解)

1.2 有理数的加减法

加法法则：
① 同号两数相加：取相同符号，绝对值相加。　例 (−3)+(−5) = −8
② 异号两数相加：取绝对值较大的符号，用大绝对值减小绝对值。　例 (−7)+3 = −4
③ 互为相反数的两数相加得 0。
减法法则：减去一个数 = 加上它的相反数。　a − b = a + (−b)
例 2　计算 (−6) − (−10) + (−4)
解：= (−6) + 10 + (−4)　〔减变加，−10 变 +10〕
= 4 + (−4) = 0
易错警示 ①（符号）：减号变加号时，后面那个数也要变相反数。−(−10) 要变成 +10，最常漏。

1.3 有理数的乘除与乘方

乘除符号：同号得正，异号得负；负因数个数为偶 → 积为正，为奇 → 积为负。
乘方：aⁿ 表示 n 个 a 相乘。负数的偶次幂为正，奇次幂为负。
科学计数法：a×10ⁿ（1 ≤ ｜a｜ < 10）。
易错警示 ②（乘方）：
(−2)² = 4（底数是 −2）　但　−2² = −4（底数是 2，负号在外）。看清负号在不在括号里！
例 3　计算 −3² + (−2)³ ÷ 4
解：= −9 + (−8) ÷ 4 = −9 + (−2) = −11
(先算乘方，−3²=−9，(−2)³=−8；再乘除，最后加减)

第二章　整式的加减

概念说明例
单项式数与字母的积3a²b，系数 3，次数 3
多项式几个单项式的和2x² − 3x + 1（三项）
同类项所含字母相同且相同字母指数也相同3x²y 与 −5x²y
合并同类项：只把系数相加减，字母和指数都不变。
去括号：括号前是「+」原样去；括号前是「−」，去掉后里面每一项都变号。
易错警示 ③（去括号变号）：−(3x − 5) 应等于 −3x + 5，常错写成 −3x − 5。
方法：去括号时，先在每一项上方标好新符号再写。
例 4　化简 5a − (3a − 2b) + (−b)
解：= 5a − 3a + 2b − b　〔去括号，第二个括号每项变号〕
= (5a − 3a) + (2b − b) = 2a + b

第三章　一元一次方程

等式性质：两边同加/减同一个数、同乘/除同一个非零数，等式仍成立。
解方程五步：① 去分母 → ② 去括号 → ③ 移项 → ④ 合并同类项 → ⑤ 系数化为 1。
易错警示 ④（去分母漏乘）：去分母时方程每一项都要乘公分母，没有分母的项也要乘！
易错警示 ⑤（移项变号）：项移过等号要变正负。口诀「过等号，变正负」。
例 5　解方程 (x − 1)/2 + 1 = x/3
解：去分母（×6，每项都乘）：3(x − 1) + 6 = 2x
去括号：3x − 3 + 6 = 2x
移项：3x − 2x = 3 − 6
合并：x = −3

3.1 应用题：找等量关系（重点难点）

类型核心等量关系
行程路程 = 速度 × 时间；相遇：两人路程和=总路程；追及：路程差=起始距离
工程工作总量=工作效率×时间（总量常设为 1）
利润利润 = 售价 − 进价；售价 = 标价 × 折扣
和差倍分抓「比…多/少」「是…的几倍」翻译成式子
例 6　某数的 3 倍比它的 2 倍多 5，求这个数。
解：设这个数为 x，则 3x = 2x + 5 → x = 5。
(复盘提问：让品言先用一句话说出"谁等于谁"，列不出关系式是应用题最大卡点)

第四章　几何图形初步

  • 直线、射线、线段：两点确定一条直线；两点之间，线段最短；两点间线段长度叫两点间的距离。
  • 角：1° = 60′，1′ = 60″（60 进制，类似时间）。
  • 余角与补角：和为 90° 互余；和为 180° 互补。同角(等角)的余角相等，补角也相等。
  • 角平分线：把一个角分成两个相等的角的射线。
例 7　一个角的补角比它的余角大多少度？
解：设角为 x，补角 (180−x)，余角 (90−x)，差 = (180−x)−(90−x) = 90°（与 x 无关）。

第五章　相交线与平行线（七下）

名称特征关系
对顶角两直线相交，相对的两角对顶角相等
邻补角有公共边，另一边互为反向延长互补（和 180°）
同位角 / 内错角 / 同旁内角「三线八角」判定与性质的载体
平行线判定（由角→平行）：同位角相等、内错角相等、同旁内角互补 → 两直线平行。
平行线性质（由平行→角）：两直线平行 → 同位角相等、内错角相等、同旁内角互补。
易错警示 ⑥：判定是"由角相等推出平行"，性质是"由平行推出角相等"，方向相反，证明时别用反。

第六章　实数（七下）

  • 算术平方根：正数 a 的正的平方根，记 √a（√a ≥ 0）。
  • 平方根：正数有两个平方根（±√a）；0 的平方根是 0；负数没有平方根。
  • 立方根：任何数都有唯一立方根，负数的立方根是负数（∛−8 = −2）。
  • 无理数：无限不循环小数，如 √2、π。实数 = 有理数 + 无理数。
易错警示 ⑦：√9 = 3（算术平方根只取正）；而 "9 的平方根" = ±3。两者问法不同，答案不同。

第七章　平面直角坐标系（七下）

  • 点的坐标 (x, y)：x 横坐标在前，y 纵坐标在后。
  • 象限符号：一(+,+)、二(−,+)、三(−,−)、四(+,−)。
  • x 轴上点 y=0，y 轴上点 x=0。
  • 平移：左右移动改变 x（右加左减），上下移动改变 y（上加下减）。

第八章　二元一次方程组（七下）

核心思想：消元（把"两个未知数"变成"一个未知数"）。
代入消元：从一个方程解出一个字母，代入另一个。
加减消元：使某字母系数相同/相反，两式相加减消去它。
例 8　解　x + y = 10 ……①　　2x − y = 5 ……②
解：①+②（消 y）：3x = 15 → x = 5；代入① → y = 5。解：x=5, y=5。

第九章　不等式与不等式组（七下）

易错警示 ⑧（最高频！）：不等式两边同乘或同除一个负数，不等号方向要改变。
例：−2x > 6 → x < −3（除以 −2，> 变 <）。
  • 解集在数轴上表示：≥、≤ 用实心点，>、< 用空心点。
  • 不等式组解集："大大取大、小小取小、大小小大取中间、大大小小无解"。

第十章　数据的收集、整理与描述（七下）

  • 全面调查（普查） vs 抽样调查（总体、个体、样本、样本容量）。
  • 统计图：条形图（看数量）、折线图（看趋势）、扇形图（看占比，圆心角 = 百分比 × 360°）。
  • 频数 = 出现次数；频率 = 频数 ÷ 总数。
