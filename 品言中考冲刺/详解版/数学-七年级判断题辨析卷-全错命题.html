参考答案与解析（家长 / 教师用，请勿先给学生）

重要说明：本卷 60 题全部是错误命题，正确判断应全部为「✗」。
设计目的：训练辨析能力、防止"想当然"。如果孩子有任何一题打了「✓」，那道知识点就是她的盲区，正是要补的洞。评分建议：判断对 0.5 分 + 改正对 0.5 分。

  1. 1. ✗　0 既不是正数也不是负数。
  2. 2. ✗　绝对值是非负数；0 的绝对值是 0，不是正数。应说"一定是非负数"。
  3. 3. ✗　数轴上右边的数总比左边大；离原点远的若在左边（负数）反而更小。
  4. 4. ✗　两个负数，绝对值大的反而小。如 −5 < −3。
  5. 5. ✗　减去一个数 = 加上它的相反数。a − b = a + (−b)。
  6. 6. ✗　(−2)³ = −8（三个 −2 相乘，奇次幂为负）。
  7. 7. ✗　−2² = −4（底数是 2，先平方再取负）；只有 (−2)² 才等于 4。
  8. 8. ✗　0 的偶次幂是 0，不是正数。应说"非零数的偶次幂为正"。
  9. 9. ✗　a 与 −a 相乘 = −a² ≤ 0，积为负数或 0，绝不是正数。
  10. 10. ✗　负因数有奇数个时积为负，偶数个时为正。
  11. 11. ✗　绝对值等于本身的数是非负数（正数和 0），漏了 0。
  12. 12. ✗　科学计数法中 1 ≤ |a| < 10，a 不能任意。
  13. 13. ✗　3a²b 的次数是各字母指数之和 = 2+1 = 3。
  14. 14. ✗　−x 的系数是 −1。
  15. 15. ✗　它是二次三项式（最高次为 2）；"三次"错。
  16. 16. ✗　同类项要求字母相同且相同字母的指数也相同；x 与 x² 指数不同，不是同类项。
  17. 17. ✗　合并同类项只把系数相加，字母和指数都不变。
  18. 18. ✗　−(a−b+c) = −a + b − c（去括号每项都变号）。
  19. 19. ✗　a 的系数是 1。
  20. 20. ✗　由等式性质，两边同加一个数，解不变。
  21. 21. ✗　去分母时每一项都要乘公分母，包括不含分母的项。
  22. 22. ✗　移项必须变号。
  23. 23. ✗　除数不能为 0，应说"除以同一个不为 0 的数"。
  24. 24. ✗　代入：3×2 − 1 = 5 ≠ 4，x=2 不是解（它是 3x−1=5 的解）。
  25. 25. ✗　由 2x=0 得 x = 0，有唯一解。
  26. 26. ✗　经过两点有且只有一条直线。
  27. 27. ✗　两点之间线段最短（不是"直线"）。
  28. 28. ✗　端点和方向都不同，不是同一条射线。
  29. 29. ✗　1° = 60′（60 进制）。
  30. 30. ✗　不一定。如 100° 的补角是 80°，比它小。
  31. 31. ✗　互为余角的和是 90°（互补才是 180°）。
  32. 32. ✗　角的大小与边的长短无关，只与张开程度有关。
  33. 33. ✗　锐角的余角 = 90° − 锐角，仍是锐角，不是钝角。
  34. 34. ✗　对顶角相等，不是互补。
  35. 35. ✗　邻补角互补（和为 180°），不一定相等。
  36. 36. ✗　应是"经过直线外一点"有且只有一条平行线（漏"直线外"）。
  37. 37. ✗　只有两直线平行时同位角才相等。
  38. 38. ✗　平行于同一直线的两直线互相平行。
  39. 39. ✗　内错角相等两直线平行；同旁内角互补才平行。
  40. 40. ✗　垂线段的长度才是点到直线的距离（距离是长度，不是线段本身）。
  41. 41. ✗　9 的平方根是 ±3；只有"算术平方根"才是 3。
  42. 42. ✗　√16 = 4（算术平方根只取正）。
  43. 43. ✗　负数有立方根，如 ∛(−8) = −2。
  44. 44. ✗　无理数是无限不循环小数；无限循环小数是有理数。
  45. 45. ✗　不一定。如 √2 + (−√2) = 0 是有理数。
  46. 46. ✗　负数没有算术平方根。
  47. 47. ✗　数轴上的点与实数一一对应，也表示无理数。
  48. 48. ✗　(−3, 2)：x<0、y>0，在第二象限。
  49. 49. ✗　(0, 5) 横坐标为 0，在 y 轴上。
  50. 50. ✗　第二象限是 (−, +)：横坐标负、纵坐标正。
  51. 51. ✗　坐标必须横坐标在前，写成（横，纵）。
  52. 52. ✗　横坐标相同，连线平行于 y 轴。
  53. 53. ✗　一个二元一次方程有无数个解。
  54. 54. ✗　xy 是二次项，不是二元一次方程。
  55. 55. ✗　消元是把二元变成一元（不是三元）。
  56. 56. ✗　x=1 时 y = 4，是确定的。
  57. 57. ✗　乘以负数时不等号方向要改变（且不能乘 0）。
  58. 58. ✗　−2x > 4 两边除以 −2，变向：x < −2。
  59. 59. ✗　x ≥ 1 含等于，用实心圆点。
  60. 60. ✗　只有 c > 0 时才有 ac > bc；c=0 或 c<0 不成立。
